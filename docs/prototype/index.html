Recipi叩き台

このプロトタイプについて

要件定義書（docs/requirements/）を叩き台として形にしたモックアップです。実バックエンドはなく、すべてブラウザ内のモックデータで動きます。要件を煮詰めるためのたたき台としてお使いください。

画面インデックス

モックの割り切り

  • 画像は色ブロック＋絵文字で代用
  • 通信待ち・エラーは「設計メモ」ONで状態切替から確認
  • 無限スクロール・カーソルページングは省略（1ページ表示）
  • 検索の正規化・AND 判定は簡易実装
  • トークン／リフレッシュ等の認証内部は省略（入力すれば成功）

設計メモの見かた

「設計メモ」をONにすると、各画面に 未確定事項・割り切り の注記と、一覧画面の 状態切替（通常／空／エラー）が表示されます。

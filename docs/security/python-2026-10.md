# Python・証明書ストアの更新（Issue #349）

Pythonを3.14.9へ更新し、ローカル・CI・Dockerを`.python-version`とDockerfileで揃える。実行時のcertifiを2026.10.19、開発環境とDockerのpipを26.2.2に固定する。既存のvenvは自動で置換しないため、利用者はPython 3.14.9でvenvを作り直してrequirements-dev.txtをインストールする。

## OpenSSLの確認方法

WindowsのPython 3.14.9ではOpenSSL 3.5.9を確認した。一方、DebianベースのDockerでは`ssl.OPENSSL_VERSION`が3.5.7と表示される。Debianはセキュリティ修正をバックポートするため、表示文字列だけで未修正とは判断しない。

Docker内の`libssl3t64`と`openssl`は`3.5.7-1~deb13u3`であり、[DSA-6531-1に対応するDebianの修正情報](https://security-tracker.debian.org/tracker/CVE-2026-84782)では修正済み。Dockerfileの共通baseステージでOSパッケージを更新し、`dpkg --compare-versions`でこの修正版以上を要求する。builderとruntimeは同じbaseを利用する。

## 検証

専用のPython 3.14.9 venvと使い捨てPostgreSQL・MinIOで検証する。backend全体のruff check、ruff format、mypy、pytestと、修正版の実行イメージに対する画像アップロードを含むWeb E2Eを対象とする。本番へのデプロイは行わない。

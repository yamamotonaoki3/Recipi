# レシピ検索

## 1. 目的・概要

ボトムナビゲーション / ナビゲーションレールの「検索」destination から、**レシピタイトル**と**材料名**を対象にレシピを探す。複数語を入れた場合は AND（すべての語を含むものだけ）。

## 2. 画面・UI

- 画面設計は [../screens/search.md](../screens/search.md)
- 「検索」destination の画面上部に**常時表示の検索入力欄**（プレースホルダ「レシピ・材料で検索」）。
- 確定すると同じ画面に結果一覧（レシピカードの縦リスト、無限スクロール）。
- 検索語チップ + 現在のフィード表示（任意のフィード切替チップ）。
- 空状態: 「『〇〇』に一致するレシピは見つかりませんでした」。
- 検索語を消すと通常のフィード表示に戻る。

## 3. 振る舞い・ルール

- 検索対象は **`recipes.title` と `ingredients.name`**。
- 入力文字列を**空白区切りの語**に分割し、**各語について「タイトルに部分一致 OR いずれかの材料名に部分一致」**を満たすレシピを返す。**語どうしは AND**。
  - 例: `玉ねぎ 豚肉` → 「玉ねぎ」を（タイトル or 材料）に含み、かつ「豚肉」も（タイトル or 材料）に含むレシピ。
- 検索対象の可視性は各フィードのルールに従う（[home-feed.md](home-feed.md) / [../non-functional.md](../non-functional.md)）。`all` / `following` / `followers` は公開レシピのみ、`favorites` は自分の非公開レシピを含み、他人のレシピで非公開化 / 削除済みのものは除外する。
- `q` は全フィード（`all` / `following` / `followers` / `favorites`）と併用できる。併用時はそのフィードの中を通常の検索マッチ規則で絞り込む。`feed=favorites` では、自分がお気に入り登録したレシピ集合の中を絞り込む。
- 結果は新着順・**カーソルページングによる無限スクロール**（[../non-functional.md](../non-functional.md)）。

### スペースと正規化の順序（重要）

処理の順番:

1. 入力文字列を受け取る（例: `"玉ねぎ 豚肉"`）
2. **まず空白で語に分割** → `["玉ねぎ", "豚肉"]`
   - 半角スペース・**全角スペース `　`**・連続スペースは、すべて語の区切りとして扱い、空文字の語は捨てる。
3. **分割後の各語を個別に正規化**（前後空白除去・小文字化・全角/半角そろえ）
   - 語の中にスペースは無いので、正規化でスペースが問題になることはない。語間スペースは手順 2 で消費済み。
4. 各語について `title_normalized` 部分一致 OR いずれかの `ingredients.name_normalized` 部分一致
5. 語どうしを AND

- そのため「スペースが消えて全部くっつく」ことはない。語の分割が先、正規化は語ごと。
- **スペース無しの入力**（例: `玉ねぎ豚肉`）は **1 語**として扱われ、「玉ねぎ豚肉」という連続文字列を含むレシピしかヒットしない（複数材料の AND 検索にはならない）。複数条件で絞りたいときはスペース区切りで入力する。
- DB の `recipes.title_normalized` / `ingredients.name_normalized` は「1 つのタイトル」「1 つの材料名」という**単一値**の正規化であり、検索語の分割とは独立した処理。

## 4. データモデル

新規テーブルなし。

- `recipes.title_normalized`（NOT NULL、index、必要なら `pg_trgm`）
- `ingredients.name_normalized`（NOT NULL、index、必要なら `pg_trgm`）
- どちらもサーバーがレシピ保存時に生成（[recipe.md](recipe.md)）。

## 5. API

### GET `/recipes?q=...`（認証必要）

- [home-feed.md](home-feed.md) の `GET /recipes` と同じエンドポイント。`q` パラメータで検索。
- `q` を空白で語に分割し、各語について `title_normalized ILIKE '%語%' OR EXISTS(ingredients.name_normalized ILIKE '%語%')` を満たすものを AND で絞り込む。
- `feed` と併用時はそのフィード集合内で適用（`favorites` を含む）。
- レスポンス形式は [home-feed.md](home-feed.md) と同じ。

```
GET /api/v1/recipes?q=玉ねぎ%20豚肉&feed=all&limit=20
```

## 6. バリデーション

| 項目 | ルール |
| --- | --- |
| `q` | 任意。空なら通常フィード。語数・長さの上限は実装時に決定（例: 5 語 / 各 30 文字） |

## 7. 受け入れ基準

- [ ] 1 語で、その語をタイトルまたは材料名に含む公開レシピが返る
- [ ] 複数語で AND 検索になる（すべての語を含むものだけ返る）
- [ ] `all` / `following` / `followers` の検索結果に非公開レシピは出ない（`feed=favorites` では自分が投稿した非公開レシピを含む）
- [ ] 全角 / 半角、大文字 / 小文字の違いがあってもヒットする
- [ ] `玉ねぎ　豚肉`（全角スペース区切り）でも 2 語 AND として扱われる
- [ ] `玉ねぎ豚肉`（スペース無し）は 1 語として扱われ、その連続文字列を含むレシピのみヒットする
- [ ] `feed=following` と `q` を併用すると、フォロー中ユーザーの公開レシピの中で検索される
- [ ] `feed=favorites` と `q` を併用すると、自分がお気に入り登録したレシピ集合の中で検索される
- [ ] 検索語が空のときは通常のフィード表示に戻る
- [ ] 該当なしのとき空状態メッセージが出る

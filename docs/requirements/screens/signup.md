# サインアップ

## 1. 目的

新規アカウントを作成する。パスワードリセット用の「秘密の質問」もここで登録する。

## 2. ナビゲーション

- 入口: [ログイン](login.md)の「新規登録」リンク。
- 出口: [ホーム](home.md)（登録成功）/ [ログイン](login.md)（「ログインへ」リンク or 戻る）。
- 戻る: ログインへ。
- 認証: 不要。

## 3. レイアウト

- アプリバー: 「新規登録」+ 戻る矢印
- メールアドレス入力
- パスワード入力（表示トグル）
- パスワード確認入力（表示トグル・一致チェック）
- 表示名入力
- **秘密の質問**: 質問文（自由入力）＋ 答え
- 登録ボタン
- 「ログインへ」リンク

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| パスワード不一致 | 確認欄の下にエラー、登録ボタンは押しても API を呼ばない |
| 必須欠落 / 文字数超過 | 各欄の下にエラー |
| error（409） | メール欄の下に「このメールアドレスは登録済みです」 |
| 送信中 | ボタンをローディング表示 |

## 5. アクションと結果

- 登録ボタン → クライアント側バリデーション（パスワード一致、必須、文字数）→ `POST /auth/signup`（`email`, `password`, `displayName`, `securityQuestion`, `securityAnswer`）。
  - 成功 → アクセス / リフレッシュトークンを受け取りホームへ（この登録では自動ログイン状態、`rememberMe` は既定 OFF 相当）。
  - 409 → メール重複エラー。
- 「ログインへ」→ [ログイン](login.md)。

## 6. 使用 API

- `POST /auth/signup`（[`../features/auth.md`](../features/auth.md)）

## 7. プラットフォーム差分

- デスクトップ: Enter で送信、Tab 順は上から。
- 秘密の質問の注意書き（「パスワードを忘れたときの本人確認に使います」）をヒントとして表示。

# 自分のレシピ一覧

## 1. 目的

自分が投稿したレシピ（公開・非公開すべて）を一覧する。機能仕様は [`../features/recipe.md`](../features/recipe.md)。

## 2. ナビゲーション

- 入口: [マイページ](my-page.md)のメニュー「自分のレシピ一覧」。
- 出口: [レシピ詳細](recipe-detail.md)（カードタップ）。
- 戻る: マイページへ。
- 認証: 必要（本人のみ）。

## 3. レイアウト

- アプリバー: 「自分のレシピ」+ 戻る矢印
- 本文: [レシピカード](components.md)の 1 リスト（公開・非公開混在）。非公開カードに「非公開」バッジ。新着順、無限スクロール
- （任意）作成導線は「＋」ボトムナビにあるため画面内には置かない

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| loading | スケルトン |
| empty | 「まだレシピを投稿していません」 |
| error | 「読み込みに失敗しました」＋「再試行」 |

## 5. アクションと結果

- 一覧取得 → `GET /users/me/recipes`。
- カードタップ → [レシピ詳細](recipe-detail.md)（本人なので編集 / 削除ボタンが出る）。
- 引っぱって更新 → 再取得。

## 6. 使用 API

- `GET /users/me/recipes`（[`../features/recipe.md`](../features/recipe.md)）

## 7. プラットフォーム差分

- デスクトップ: 最大幅で中央寄せ。

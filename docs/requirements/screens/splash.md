# スプラッシュ

## 1. 目的

起動直後に一瞬表示し、保存済みトークンの有無で次の画面を決める。

## 2. ナビゲーション

- 入口: アプリ起動時（常に最初）。
- 出口: [ホーム](home.md)（自動再ログイン成功）/ [ログイン](login.md)（それ以外）。
- 戻る: 不可（履歴に残さない）。
- 認証: 不要。

## 3. レイアウト

- 中央にロゴ。
- 必要なら小さなスピナー。

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| 判定中 | ロゴ + スピナー（通常一瞬） |
| ネットワーク遅延で自動再ログインが長引く | 数秒でタイムアウトし、ログイン画面へフォールバック |

## 5. アクションと結果

- 「ログインを保持」ON で保存済みリフレッシュトークンがある → `POST /auth/refresh` を試行。
  - 成功 → アクセストークンを保持しホームへ。
  - 失敗（無効 / 失効 / リユース検知）→ ローカルのトークンを破棄しログインへ。
- 保存済みトークンなし → ログインへ。

## 6. 使用 API

- `POST /auth/refresh`（[`../features/auth.md`](../features/auth.md)）

## 7. プラットフォーム差分

- モバイル: OS のスプラッシュ（起動画像）からシームレスに繋ぐ。
- デスクトップ: ウィンドウ表示直後に同じ判定。

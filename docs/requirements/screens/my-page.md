# マイページ

## 1. 目的

自分のプロフィール概要と、アカウント関連メニューへの入口。旧「アカウントメニュー」を画面に昇格したもの。

> **MVP でのスコープ**: Phase 4（MVP）では **表示名 ＋ ログアウト**のみ。フォロー数 / フォロワー数・「フォロー・フォロワー」メニュー・アバター表示は Phase 5、「自分のレシピ一覧」への導線は Phase 2 で使えるので入れる。「プロフィール編集」は Phase 1 の表示名編集のみ。アカウント削除（[プロフィール編集](profile-edit.md)内）は Phase 9（[../roadmap.md](../roadmap.md)「MVP ライン」）。

## 2. ナビゲーション

- 入口: ボトムナビ / レールの「マイページ」。
- 出口: [自分のレシピ一覧](my-recipes.md) / [フォロー・フォロワー](connections.md) / [プロフィール編集](profile-edit.md) / [ログイン](login.md)（ログアウト）。
- 戻る: マイページのスタックを 1 つ戻す。「マイページ」再タップ → ルートへ。
- 認証: 必要。

## 3. レイアウト（上 → 下）

- アプリバー: 「マイページ」
- プロフィール概要:
  - アバター + 表示名
  - フォロー数 / フォロワー数（タップで[フォロー・フォロワー](connections.md)の該当タブ）
- メニュー（リスト）:
  1. 自分のレシピ一覧 → [my-recipes.md](my-recipes.md)
  2. フォロー・フォロワー → [connections.md](connections.md)
  3. プロフィール編集 → [profile-edit.md](profile-edit.md)
  4. ログアウト

> - **お気に入りレシピ**はここではなく[ホーム](home.md)の「お気に入りレシピ」タブ。
> - **アカウント削除**は[プロフィール編集](profile-edit.md)画面内のボタン。

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| loading | 概要部分をスケルトン |
| error（概要取得失敗） | 「読み込みに失敗しました」＋「再試行」。メニューは表示 |

## 5. アクションと結果

- 概要取得 → `GET /users/{自分のID}`（本人取得なので全項目 + フォロー数 / フォロワー数）。
- 「ログアウト」→ [確認ダイアログ](components.md)（任意）→ `POST /auth/logout`（リフレッシュトークン失効）→ 端末のトークンを破棄 → [ログイン](login.md)へ。

## 6. 使用 API

- `GET /users/{id}`（自分）
- `POST /auth/logout`
- （[`../features/profile.md`](../features/profile.md) / [`../features/auth.md`](../features/auth.md)）

# ホーム

## 1. 目的

ログイン後の中心画面。最上部の**常時固定の検索窓**でレシピを探し、4 つのサブタブでフィードを切り替えて見る。機能仕様は [`../features/home-feed.md`](../features/home-feed.md)、検索のマッチ規則は [`../features/search.md`](../features/search.md)。

## 2. ナビゲーション

- 入口: ボトムナビ / レールの「ホーム」。ログイン成功後の既定 destination。検索用の独立 destination は無い。
- 出口: [レシピ詳細](recipe-detail.md)（カードタップ）/ [閲覧履歴](history.md)（アプリバーの履歴アイコン）。ボトムナビで他 destination へ。
- 戻る: ホームのスタックを 1 つ戻す。ホームのルートで戻る → アプリ終了確認。「ホーム」再タップ → ルートへ戻し最上部へスクロール、検索窓に入力があればクリア。
- 認証: 必要。

## 3. レイアウト（上 → 下）

- アプリバー: ロゴ + 右に**履歴アイコン**（タップで[閲覧履歴](history.md)。[`../features/view-history.md`](../features/view-history.md)）
- **検索窓**（画面最上部に常時固定。プレースホルダ「レシピ・材料で検索」）。本文をスクロールしても残る。× で入力をクリア
- **サブタブ**（横並び、スワイプ可）: 全体 / フォロー / フォロワー / お気に入りレシピ
- 本文: [レシピカード](components.md)の縦リスト。カーソルページングによる無限スクロール
  - **検索窓が空のとき**: 選択中サブタブの通常フィード
  - **検索語を確定したとき**: 選択中サブタブの集合を検索語で絞り込んだ結果リスト。上部に検索語チップ（× でクリア）
- 「＋」はボトムナビにあるため画面内 FAB は不要（重複させない）

| サブタブ | 内容（検索窓が空のとき） | 並び |
| --- | --- | --- |
| 全体 | すべての公開レシピ | 新着順 |
| フォロー | フォロー中ユーザーの公開レシピ | 新着順 |
| フォロワー | 自分をフォローしているユーザーの公開レシピ | 新着順 |
| お気に入りレシピ | 自分がお気に入り登録したレシピ（自分の非公開も含む） | お気に入り登録日時の新しい順 |

- 検索語があるときは、**そのサブタブの集合の中**を [`../features/search.md`](../features/search.md) のマッチ規則（タイトル + 材料名、空白区切り AND）で絞り込む。

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| 初回 loading | スケルトンのカードリスト |
| 追加 loading | 末尾にスピナー |
| 検索語あり・該当なし | 「『〇〇』に一致するレシピは見つかりませんでした」 |
| empty（全体・検索なし） | 「まだレシピがありません」 |
| empty（フォロー・検索なし） | 「気になる投稿者をフォローすると、ここに新着レシピが並びます」 |
| empty（フォロワー・検索なし） | 「フォロワーが増えると、その人のレシピがここに並びます」 |
| empty（お気に入りレシピ・検索なし） | 「お気に入りに追加したレシピがここに表示されます」 |
| error | 「読み込みに失敗しました」＋「再試行」 |

## 5. アクションと結果

- 検索窓で確定（Enter / 検索キー）→ `GET /recipes?q=...&feed=<選択中サブタブ>`。`q` は空白（半角・全角・連続）区切りで語に分割し AND（[`../features/search.md`](../features/search.md)）。
- 検索語チップの × / 検索窓を空にする → その場でそのサブタブの通常フィードに戻る。
- サブタブ切替 → その `feed` を取得（`GET /recipes?feed=...`。検索語が残っていればその `feed` 集合内で再検索）。切替時にスクロール位置はサブタブごとに保持。
- カードタップ → [レシピ詳細](recipe-detail.md)。
- 履歴アイコンタップ → [閲覧履歴](history.md)。
- 引っぱって更新 → 先頭から再取得。
- フォロー / お気に入りの増減はリアルタイム反映しない。次にそのサブタブを表示（再取得）したとき反映。

## 6. 使用 API

- `GET /recipes?feed=all|following|followers|favorites&q=&limit=&cursor=`（[`../features/home-feed.md`](../features/home-feed.md) / [`../features/search.md`](../features/search.md)）

## 7. プラットフォーム差分

- モバイル: サブタブはスワイプでも切替。検索窓にフォーカスするとキーボードが上がる。
- デスクトップ: サブタブはクリック。リストは最大幅で中央寄せ。左レールが常時表示。Esc で検索窓をクリア。

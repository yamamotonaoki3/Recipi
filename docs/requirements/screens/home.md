# ホーム

## 1. 目的

ログイン後の中心画面。4 つのサブタブでレシピのフィードを切り替えて見る。機能仕様は [`../features/home-feed.md`](../features/home-feed.md)。

## 2. ナビゲーション

- 入口: ボトムナビ / レールの「ホーム」。ログイン成功後の既定 destination。
- 出口: [レシピ詳細](recipe-detail.md)（カードタップ）。ボトムナビで他 destination へ。
- 戻る: ホームのスタックを 1 つ戻す。ホームのルートで戻る → アプリ終了確認。「ホーム」再タップ → ルートへ戻し最上部へスクロール。
- 認証: 必要。

## 3. レイアウト

- アプリバー: ロゴ（検索バーは無し。検索は「検索」destination）
- **サブタブ**（横並び、スワイプ可）: 全体 / フォロー / フォロワー / お気に入りレシピ
- 本文: [レシピカード](components.md)の縦リスト。カーソルページングによる無限スクロール
- 「＋」はボトムナビにあるため画面内 FAB は不要（重複させない）

| サブタブ | 内容 | 並び |
| --- | --- | --- |
| 全体 | すべての公開レシピ | 新着順 |
| フォロー | フォロー中ユーザーの公開レシピ | 新着順 |
| フォロワー | 自分をフォローしているユーザーの公開レシピ | 新着順 |
| お気に入りレシピ | 自分がお気に入り登録したレシピ（自分の非公開も含む） | お気に入り登録日時の新しい順 |

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| 初回 loading | スケルトンのカードリスト |
| 追加 loading | 末尾にスピナー |
| empty（フォロー） | 「気になる投稿者をフォローすると、ここに新着レシピが並びます」 |
| empty（フォロワー） | 「フォロワーが増えると、その人のレシピがここに並びます」 |
| empty（お気に入りレシピ） | 「お気に入りに追加したレシピがここに表示されます」 |
| error | 「読み込みに失敗しました」＋「再試行」 |

## 5. アクションと結果

- サブタブ切替 → そのフィードを取得（`GET /recipes?feed=...`）。切替時にスクロール位置はタブごとに保持。
- カードタップ → [レシピ詳細](recipe-detail.md)。
- 引っぱって更新 → 先頭から再取得。
- フォロー / お気に入りの増減はリアルタイム反映しない。次にそのタブを表示（再取得）したとき反映。

## 6. 使用 API

- `GET /recipes?feed=all|following|followers|favorites&limit=&cursor=`（[`../features/home-feed.md`](../features/home-feed.md)）

## 7. プラットフォーム差分

- モバイル: サブタブはスワイプでも切替。
- デスクトップ: サブタブはクリック。リストは最大幅で中央寄せ。左レールが常時表示。

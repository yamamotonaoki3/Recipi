# 共通コンポーネント

画面をまたいで使う UI 部品の定義。各画面ファイルはここを参照する。

## ボトムナビゲーション / ナビゲーションレール

- 4 destination: ホーム / ＋（作成）/ 通知 / マイページ（[navigation.md](navigation.md)）。検索は独立 destination を持たず[ホーム](home.md)上部の検索窓で行う。
- 各アイコン ＋ ラベル。現在の destination をハイライト。
- 通知アイコンに未読バッジ（1〜99、それ以上は `99+`）。
- モバイル = 下部固定バー、デスクトップ = 左レール。

## アプリバー（各画面の上部バー）

- 左: 戻る矢印（スタック 2 階層目以降）または無し。
- 中央 / 左: タイトル（ホームはロゴ）。
- 右: 文脈アクション（0〜2 個）。
- スクロールで縮む挙動は任意（実装時に決定）。

## レシピカード

一覧（ホーム各タブ / 検索結果 / 閲覧履歴 / 自分のレシピ一覧 / ユーザープロフィール / お気に入り）で 1 レシピを表す。

- サムネイル画像（`recipes.thumbnail_key` からサーバーが生成した表示用 URL。無ければプレースホルダ）
- タイトル（1〜2 行で省略）
- 投稿者（アバター + 表示名）
- お気に入り数（♡ + `recipes.favorite_count`）
- 自分のレシピ一覧でのみ「非公開」バッジ
- タップ → [レシピ詳細](recipe-detail.md)

## ユーザー行

一覧（フォロー・フォロワー一覧など。将来のユーザー検索も同じ部品）で 1 ユーザーを表す。

- アバター + 表示名
- フォロー状態ボタン（「フォロー」/「フォロー中」）。自分自身の行にはボタンを出さない
- タップ（ボタン以外の領域）→ [ユーザープロフィール](user-profile.md)（自分なら[マイページ](my-page.md)）

## 感想アイテム

レシピ詳細の感想一覧の 1 件（[`../features/comment.md`](../features/comment.md)）。

- 投稿者行（アバター + 表示名）+ 投稿日時
- 本文
- 添付画像（あれば。`image_key` から生成した URL）
- 自分の感想: 「編集」「削除」
- 自分がレシピ投稿者: 他人の感想にも「削除」

## 通知アイテム

通知一覧の 1 件（[`../features/notification.md`](../features/notification.md)）。

- 行為者アバター
- 本文（種別ごとの定型文）
- 日時
- 未読は背景色などで強調
- タップ → 対象へ遷移し既読化（[navigation.md](navigation.md) ディープリンク）

## 確認ダイアログ

破壊的操作の前に出すモーダル。

- タイトル + 本文（何が起きるかを明記）
- 「実行」（破壊的操作は赤）/「キャンセル」
- 用途: レシピ削除、感想削除、アカウント削除、フォロー解除（任意）

## パスワード入力欄

グローバル CLAUDE.md「ログイン機能の標準UI要件」準拠。

- 表示 / 非表示トグルボタンを併設
- 「新しいパスワードを設定する」画面（サインアップ / パスワードリセット）では確認用の再入力欄を設け、不一致はクライアント側でエラー表示し送信をブロック

## 状態表示

すべての一覧・詳細で共通。

| 状態 | 表示 |
| --- | --- |
| loading（初回） | スケルトン or スピナー |
| loading（追加ページ） | リスト末尾にスピナー（無限スクロール） |
| empty | 画面ごとの空状態メッセージ（各画面ファイル参照） |
| error（取得失敗） | 「読み込みに失敗しました」＋「再試行」ボタン |
| 未認証（401） | トークン破棄 → ログイン画面へ（[navigation.md](navigation.md)） |
| 権限なし（403）/ 不在（404） | 「表示できません」＋前の画面へ戻る導線 |

## スナックバー / トースト

- 操作結果の一時通知（例: 「レシピを保存しました」「フォローしました」「削除しました」）。
- エラーの軽微な通知（例: 「通信エラー。もう一度お試しください」）。
- 破壊的操作の取り消し（Undo）は当面なし（→ [`../todo.md`](../todo.md)）。

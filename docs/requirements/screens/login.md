# ログイン

## 1. 目的

メールアドレスとパスワードでログインする。

## 2. ナビゲーション

- 入口: [スプラッシュ](splash.md)（未ログイン）/ 認証ゲート（[navigation.md](navigation.md)）/ ログアウト後 / アカウント削除後 / [パスワードリセット](password-reset.md)成功後。
- 出口: [ホーム](home.md)（または認証ゲートで保留していた画面）/ [サインアップ](signup.md) / [パスワードリセット](password-reset.md)。
- 戻る: このスタックのルート。戻るキーでアプリ終了確認。
- 認証: 不要（ログイン済みならスプラッシュがホームへ流す）。

## 3. レイアウト

- アプリバー: ロゴ or 「ログイン」
- メールアドレス入力
- パスワード入力（表示トグル。[components.md](components.md) パスワード入力欄）
- **「ログインを保持」チェックボックス**
- ログインボタン
- 「パスワードをお忘れの方」リンク
- 「新規登録」リンク

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| 送信中 | ボタンをローディング表示、入力を無効化 |
| error（401） | 「メールアドレスまたはパスワードが違います」（メール / パスワードのどちらが誤りかは示さない） |
| error（通信失敗） | スナックバー「通信エラー。もう一度お試しください」 |

## 5. アクションと結果

- ログインボタン → `POST /auth/login`（`email`, `password`, `rememberMe`）。
  - 成功 → アクセス / リフレッシュトークンを受け取り、`rememberMe` ON ならリフレッシュトークンを端末のセキュアストレージに永続保存。ホーム（または保留画面）へ。
  - 失敗 → 上記エラー。
- 「新規登録」→ [サインアップ](signup.md)。
- 「パスワードをお忘れの方」→ [パスワードリセット](password-reset.md)。

## 6. 使用 API

- `POST /auth/login`（[`../features/auth.md`](../features/auth.md)）

## 7. プラットフォーム差分

- デスクトップ: Enter で送信。Tab 順（メール → パスワード → 保持 → ボタン）。
- 「ログインを保持」OFF のとき、リフレッシュトークンをセキュアストレージに永続化しない（[`../non-functional.md`](../non-functional.md)）。

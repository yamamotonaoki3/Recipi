# 検索

## 1. 目的

レシピをタイトル・材料名で探す。機能仕様は [`../features/search.md`](../features/search.md)。

## 2. ナビゲーション

- 入口: ボトムナビ / レールの「検索」。
- 出口: [レシピ詳細](recipe-detail.md)（結果タップ）。
- 戻る: 検索スタックを 1 つ戻す。「検索」再タップ → 入力をクリアしルートへ。
- 認証: 必要。

## 3. レイアウト

- 画面上部に**常時表示の検索フィールド**（プレースホルダ「レシピ・材料で検索」）
- （任意）フィード切替チップ: 全体 / フォロー / フォロワー / お気に入りレシピ（既定は全体）
- 本文:
  - **検索語が空のとき**: 選択中フィードの通常のレシピ一覧（[`../features/search.md`](../features/search.md)。既定は「全体」フィード）
  - **検索語を確定したとき**: [レシピカード](components.md)の結果リスト（無限スクロール）
- 検索語チップ（現在の検索語）を結果上部に表示、× でクリア（→ 空のとき = 通常のフィード一覧に戻る）
- 検索履歴・人気タグなどのサジェスト UI は将来検討（→ [`../todo.md`](../todo.md)）

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| 検索語が空 | 選択中フィードの通常のレシピ一覧（[home.md](home.md) の各タブと同じ内容） |
| loading | スケルトン |
| 該当なし（検索語あり） | 「『〇〇』に一致するレシピは見つかりませんでした」 |
| error | 「読み込みに失敗しました」＋「再試行」 |

## 5. アクションと結果

- 検索フィールドで確定（Enter / 検索キー）→ `GET /recipes?q=...&feed=...`。
  - `q` は空白（半角 / 全角 / 連続）区切りで語に分割し AND（[`../features/search.md`](../features/search.md)）。
  - `feed` を選んでいればその集合内で絞り込み（`favorites` 含む）。
- 結果タップ → [レシピ詳細](recipe-detail.md)。
- 検索語を空にする → 通常のフィード表示（選択中フィードの一覧）に戻る。

## 6. 使用 API

- `GET /recipes?q=&feed=&limit=&cursor=`（[`../features/search.md`](../features/search.md) / [`../features/home-feed.md`](../features/home-feed.md)）

## 7. プラットフォーム差分

- モバイル: 検索フィールドにフォーカスするとキーボードが上がる。
- デスクトップ: 起動時に検索フィールドへ自動フォーカスしてよい。Esc でクリア。

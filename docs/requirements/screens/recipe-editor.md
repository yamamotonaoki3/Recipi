# レシピ作成 / 編集

## 1. 目的

レシピを新規作成、または自分のレシピを編集する。機能仕様は [`../features/recipe.md`](../features/recipe.md)（入力項目・バリデーション・行編集 UX）、画像は [`../features/image.md`](../features/image.md)、単位は [`../features/unit.md`](../features/unit.md)。

## 2. ナビゲーション

- 入口:
  - 作成: ボトムナビ / レールの「＋」→ フルスクリーンダイアログ（モーダル）で開く。
  - 編集: [レシピ詳細](recipe-detail.md)の「編集」。
- 出口: [レシピ詳細](recipe-detail.md)（保存成功）/ 呼び出し元（破棄）。
- 戻る: 未保存の変更があれば[確認ダイアログ](components.md)「編集内容を破棄しますか？」。
- 認証: 必要。編集は投稿者本人のみ（他人は開けない）。

## 3. レイアウト（上 → 下）

- アプリバー: 「×」（閉じる）+ タイトル「レシピを作成」/「レシピを編集」+ 右に「保存」
- **サムネイル画像**: 1 枚選択（変更 / 削除）
- タイトル（単一行、1〜120）
- 説明（複数行、0〜2000）
- 何人分（数値ステッパー、1〜99）
- **材料の行リスト**: 各行「材料名 / 数量 / 単位」。`+` で行追加、各行に削除、並べ替え（ドラッグ or 上下ボタン）。単位欄はオートコンプリート（[`../features/unit.md`](../features/unit.md)）、入力に応じて `大さじ 2` などのプレビュー
- **手順の行リスト**: 各行「本文 + 画像を追加ボタン」。`+` で行追加、各行に削除、並べ替え。行頭に手順番号を自動表示
- 公開フラグ（トグル、既定 OFF）

## 4. 状態

| 状態 | 表示 |
| --- | --- |
| バリデーションエラー | 各欄の下にメッセージ。サーバー 400 も同じ欄に反映（複数まとめて） |
| 保存中 | 「保存」をローディング表示、入力を無効化 |
| 画像アップロード中 | 該当のサムネ / 手順行にスピナー |
| error（通信） | スナックバー「保存に失敗しました」。入力は保持 |

## 5. アクションと結果

- 画像選択（サムネ / 手順）→ `POST /images` で一時アップロード → 返った `key` を保持。
- 「保存」→ クライアント側バリデーション → 空の手順行を除外 →
  - 作成: `POST /recipes`（`thumbnailKey`, `steps[].imageKey` を含む）→ 成功でモーダルを閉じ[レシピ詳細](recipe-detail.md)へ。
  - 編集: `PUT /recipes/{id}`（材料・手順は全入れ替え。**残したい画像はキーを再送**、省略 / `null` は画像なし。[`../features/image.md`](../features/image.md)）→ 詳細へ戻る。
- 並べ替え → `position` を 1 起点の連番に正規化。手順画像は手順に付いて動く。
- 公開レシピを新規投稿 → サーバーがフォロワーへ通知（`followee_new_recipe`）。

## 6. 使用 API

- `POST /images`
- `POST /recipes` / `PUT /recipes/{id}`
- `GET /recipes/{id}`（編集時の初期値ロード）
- （[`../api.md`](../api.md)）

## 7. プラットフォーム差分

- モバイル: フルスクリーンダイアログ。画像はカメラ / ギャラリー。並べ替えはドラッグ。
- デスクトップ: 大きめのダイアログ（フルスクリーンでなくてよい、実装時に確定）。画像は OS ファイル選択。並べ替えは上下ボタンも用意。

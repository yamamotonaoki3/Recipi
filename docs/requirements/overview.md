# 概要・目的

## コンセプト

Recipi は、**携帯電話から手軽にレシピを登録・共有できるアプリ**である。モバイルファーストだが、**Android / iOS に加えてデスクトップ（Windows・macOS）** でも使える。料理中・買い物中でも片手で素早くレシピを記録し、他ユーザーの公開レシピを検索・閲覧し、気に入った投稿者をフォローしたり、レシピをお気に入り登録したり、作ってみた感想を（写真つきで）書いたりできる。

対応プラットフォーム: **Android / iOS / Desktop（Windows・macOS）**。ブラウザ（Web）版は当面対象外（[todo.md](todo.md)）。技術構成は [tech-stack.md](tech-stack.md)。

## 想定ユーザー

| ペルソナ | 主な利用シーン |
| --- | --- |
| 自炊する個人 | 自分の定番レシピを記録し、後から見返す |
| レシピを共有したい人 | 作ったレシピを公開し、他ユーザーに見てもらう |
| レシピを探す人 | 検索やホームのフィードで作るものを決める |
| 気に入った投稿者を追いたい人 | 投稿者をフォローし、その人の新着レシピを追う |
| 作ってみた人 | レシピに感想を書く／お気に入りに入れておく |

## 主なユースケース

1. アカウント登録・ログインする（パスワードを忘れたら秘密の質問でリセット）
2. レシピを新規作成する（タイトル・説明・何人分・材料・手順・サムネイル画像・手順ごとの画像・公開設定）
3. ホームで「全体 / フォロー / フォロワー / お気に入りレシピ」のフィードを見る
4. タイトルや材料名でレシピを検索する
5. レシピをお気に入り登録し、後でホームの「お気に入りレシピ」タブから見返す
6. レシピに感想（コメント）を書く（写真を 1 枚添えられる）
7. 他ユーザーのプロフィールを見てフォロー / フォロー解除する
8. 自分のフォロー中 / フォロワーの一覧を確認する
9. 通知（フォロー / お気に入り / 感想 / フォロー中の新着レシピ）を確認する
10. 自分のレシピを編集・削除する、自分の投稿一覧を確認する
11. 表示名・アバター・SNS リンクを編集する
12. アカウントを削除する

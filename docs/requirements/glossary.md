# 用語集

| 用語 | 定義 |
| --- | --- |
| レシピ | タイトル・説明・何人分・材料・手順・サムネイル画像・手順画像・公開フラグからなる投稿。作成者を「投稿者」と呼ぶ |
| 投稿者 | そのレシピを作成したユーザー。更新・削除・画像操作ができる唯一のユーザー |
| 公開 / 非公開 | レシピの `is_public`。非公開レシピは投稿者本人以外に一切表示しない（フィード・検索・プロフィール・感想すべて）。ただしお気に入りは「自分の非公開レシピ」を自分でつけられる |
| 何人分 | そのレシピが想定する人数（整数 1〜99、必須） |
| 材料 | 「材料名 + 数量（任意）+ 単位（任意）」の 1 行。レシピは 1 行以上の材料を持つ |
| 材料グループ | 材料をまとめる見出し（例「合わせ調味料A」「生地B」）。レシピは 1 個以上の材料グループを持ち、各グループに名前（任意）＋材料リストがある。グループが 1 つで名前なし = 従来のフラットな材料リスト。`ingredient_groups` テーブル |
| 材料のレシピ参照 | 材料行が自分の別レシピへのリンクになっているもの（例「自家製〇〇だれ」）。詳細で材料名タップ → そのレシピ詳細へ。参照先削除時は名前を残しリンク無効。`ingredients.ref_recipe_id` / `ref_recipe_title` |
| 手順 | 順序付きのテキスト 1 行 ＋ 任意の画像 1 枚。`position`（1 起点の連番）で順序を管理する。グループ化はしない |
| サムネイル画像 | レシピを代表する画像 1 枚。一覧カード・レシピ詳細の先頭に表示。画像カルーセルは無い |
| 手順画像 | 各手順に添付できる画像 1 枚。レシピ詳細で手順本文の下に縦に表示 |
| 感想画像 | 感想（コメント）に添付できる画像 1 枚。S3 互換ストレージに保存 |
| `placement`（単位の配置） | 単位を数値の前に出すか後ろに出すか。`suffix`（既定、`200 g`）/ `prefix`（`大さじ 2`）。`prefix` は `大さじ` `小さじ` のみ |
| カーソルページング | 一覧を「前回の末尾位置（cursor）から次の N 件」で取得する方式。オフセット方式と違い、新規投稿による重複・抜けが起きない。全一覧と感想スレッドで採用（無限スクロール） |
| デスクトップアプリ | Windows / macOS にインストールして使うアプリ。Compose Multiplatform Desktop（JVM）でモバイルと UI を共有 |
| 単位マスター（`units`） | アプリ全体で共有する材料単位の候補リスト。入力補完に使う。未登録の単位は保存時に自動追加される |
| 正規化 / `normalized` / `*_normalized` | 検索・重複判定のために、前後空白除去・小文字化・全角/半角そろえをした文字列 |
| ホームフィード | ログイン後のホーム画面。「全体 / フォロー / フォロワー / お気に入りレシピ」の 4 タブ。すべて無限スクロール |
| フォロー（片方向） | あるユーザーが別のユーザーを一方的に追う関係。承認は不要。相互フォローは自動では起きないが、双方がフォローし合えば成立する |
| フォロー中 | 自分がフォローしているユーザー |
| フォロワー | 自分をフォローしているユーザー |
| お気に入り | ユーザーがレシピに付ける「後で見る」マーク（♡）。レシピ詳細のボタンで登録 / 解除。一覧はホームの「お気に入りレシピ」タブ |
| 感想（コメント） | レシピに対して投稿者本人以外が書く自由記述のテキスト。1 レシピに複数 |
| 通知 | 自分に関係する出来事（フォローされた / お気に入りされた / 感想がついた / フォロー中の新着レシピ）をアプリ内で知らせるもの。ボトムナビ / レールの「通知」アイコンに未読数バッジ |
| 未読 | 通知の `read_at` が NULL の状態 |
| アバター | ユーザーのプロフィール画像 |
| 公開トグル | プロフィールのメール / X / Instagram / その他 URL を「プロフィールに表示するかどうか」の項目別スイッチ。既定は非公開 |
| 秘密の質問 | サインアップ時に登録する「質問文（自由入力）＋ 答え」。パスワードリセットの本人確認に使う。答えはハッシュ保存 |
| アクセストークン | API 認証に使う短命のトークン（例: 15 分） |
| リフレッシュトークン | アクセストークンを更新するための長命トークン。ローテーション方式で 1 回使い切り |
| トークンローテーション | リフレッシュトークンを使うたびに新しいものへ差し替え、古いものを無効化する方式。無効化済みトークンの再提示（リユース）を検知したらチェーン全体を失効 |
| ログインを保持 | ログイン画面のチェックボックス。ON でリフレッシュトークンを端末に永続保存し自動再ログイン、OFF で永続化しない |
| カウント列キャッシュ | フォロー数 / フォロワー数 / お気に入り数 / 感想数を集計クエリではなく非正規化カラム（`users.follower_count` 等）で保持し、増減で更新する方式。トランザクション方針は [non-functional.md](non-functional.md) |
| レシピカード | 一覧画面で 1 レシピを表す共通コンポーネント（サムネイル / タイトル / 投稿者 / お気に入り数）。[screens/components.md](screens/components.md) 参照 |
| ユーザー行 | 一覧で 1 ユーザーを表す共通コンポーネント（アバター / 表示名 / フォロー状態ボタン）。[screens/components.md](screens/components.md) 参照 |
| ボトムナビゲーション | モバイルで画面下部に置く主ナビ。5 destination（ホーム / 検索 / ＋ / 通知 / マイページ）。[screens/navigation.md](screens/navigation.md) 参照 |
| ナビゲーションレール | デスクトップ / 広幅で画面左に置く主ナビ。ボトムナビと同じ 5 destination |
| マイページ | 自分のプロフィール概要 ＋ アカウント関連メニュー（自分のレシピ一覧 / フォロー・フォロワー / プロフィール編集 / ログアウト）の destination。旧「アカウントメニュー」を画面化したもの |
| destination | ボトムナビ / レールで切り替える主要な行き先。5 つ |
| アプリバー | 各画面の上部の薄いバー（タイトル + 戻る + 文脈アクション）。旧「トップアプリバー」（検索バー常駐 + アカウントメニュー）は廃止 |
| MVP | 初回リリースに含める機能範囲。未確定。[roadmap.md](roadmap.md) 参照 |

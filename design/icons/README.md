# アイコン素材（原本の置き場）

Recipi のアプリアイコン・ファビコン・スプラッシュの **原本（マスター画像）** を置くフォルダ。
ここに画像を置いて生成コマンドを実行すると、Expo（iOS / Android / Web）と
Tauri（Windows / macOS）の各プラットフォーム向けの画像が自動で作られる。

配布物に入るのは生成後の画像（`expoApp/assets/images/` と `expoApp/src-tauri/icons/`）で、
このフォルダの原本はアプリにバンドルされない。原本と生成物を分けて管理するのが目的。

## 置くファイル

| ファイル                  | 必須     | 仕様                                                                                                                                                                                                            |
| ------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app-icon.png`            | 必須     | **1024x1024 の正方形 PNG**。**角丸を付けず、背景を四隅まで塗りつぶす**（フルブリード）。角丸は iOS / Android / Windows がそれぞれ自動で付けるため、画像側で丸めると二重になったり、角の塗り残しが黒く出たりする |
| `app-icon-foreground.png` | 強く推奨 | **ロゴだけを切り出した、背景が完全に透過した PNG**（1024x1024 推奨）。Android のアダプティブアイコンの前景と、スプラッシュのロゴに使う                                                                          |
| `splash-icon.png`         | 任意     | スプラッシュのロゴを別画像にしたい場合のみ。透過 PNG 推奨。正方形・1024px の制約は無い。省略時は `app-icon-foreground.png` →（それも無ければ）`app-icon.png` を使う                                             |

> **なぜ 2 枚必要か**: Android は端末ごとにアイコンを円・角丸四角などへ切り抜くため、
> 「背景」と「前景（ロゴ）」を分けて渡す仕様になっている（アダプティブアイコン）。
> 前景が透過していないと、円の中に四角が浮いたような見た目になる。

> **アダプティブアイコンのセーフゾーン**: 切れてほしくない要素は
> **中央 66%（1024px なら中央 676px 四方）** の内側に収める。
> `app-icon-foreground.png` を用意した場合は「すでにセーフゾーンを考慮済み」とみなしてそのまま使う。
> 省略して `app-icon.png` から代用する場合だけ、スクリプトが中央 66% へ縮小して透明の余白を足す。

## 生成のしかた

```bash
cd expoApp
npm run gen:icons
```

生成先:

| 生成先                                              | 用途                                                  |
| --------------------------------------------------- | ----------------------------------------------------- |
| `expoApp/assets/images/icon.png`                    | iOS / 汎用アプリアイコン（1024x1024）                 |
| `expoApp/assets/images/favicon.png`                 | Web（ブラウザのタブ）のファビコン（48x48）            |
| `expoApp/assets/images/android-icon-foreground.png` | Android アダプティブアイコンの前景（512x512）         |
| `expoApp/assets/images/android-icon-background.png` | 同 背景（512x512・単色）                              |
| `expoApp/assets/images/android-icon-monochrome.png` | 同 モノクロ版（432x432・テーマアイコン用）            |
| `expoApp/assets/images/splash-icon.png`             | スプラッシュのロゴ（512x512）                         |
| `expoApp/src-tauri/icons/`                          | デスクトップ用一式（`.ico` / `.icns` / 各サイズ PNG） |

生成後は差分を確認してコミットする（生成物もリポジトリで管理している）。

## 背景色はここでは持たない

アダプティブアイコンの背景色とスプラッシュの背景色は画像ではなく
[`../../expoApp/app.json`](../../expoApp/app.json) の設定値で管理している。

- `expo.android.adaptiveIcon.backgroundColor` … Android アイコンの背景色
- `expo.plugins` の `expo-splash-screen` の `backgroundColor` … スプラッシュの背景色

アイコンのデザインを変えるときは、この 2 つの色も合わせて見直すこと。
